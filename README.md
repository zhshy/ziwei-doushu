# 紫微斗数 · 排盘与解读

**[在线使用（免安装）](https://zhshy.github.io/ziwei-doushu/)** · **[下载单文件版](https://github.com/zhshy/ziwei-doushu/raw/main/index.html)** · **[源码仓库](https://github.com/zhshy/ziwei-doushu)** · **[问题反馈](https://github.com/zhshy/ziwei-doushu/issues)** · **[更新记录](https://github.com/zhshy/ziwei-doushu/commits/main)** · **[授权与来源](NOTICE.md)**

输入阳历生辰即可起盘，支持本命 / 大限 / 流年三种视角，在十二宫逐项给出本地解读、倪师体系要点与可选的 AI 评语。整个应用只有一个 HTML 文件，无需安装、无需注册、无后端。

---

## 怎么用

| 方式 | 做法 | 适合 |
|---|---|---|
| 在线使用 | 直接打开 [zhshy.github.io/ziwei-doushu](https://zhshy.github.io/ziwei-doushu/) | 想马上排一张盘 |
| 单文件离线 | 下载 [index.html](https://github.com/zhshy/ziwei-doushu/raw/main/index.html)，双击用浏览器打开 | 不想联网、想长期留存 |
| 从源码构建 | `git clone` 后执行 `npm run build` | 想改解读文字或样式 |

出生日期按「年 / 月 / 日」三个框分开填，月份与闰年天数会自动校验（例如 2 月只有 28 天时会提示）。离线使用时，排盘与本地解读全部在本机完成；只有点击「AI 评语」才会联网。

## 功能

### 排盘

- 十二宫方格，十四主星带庙旺得利平不陷七档亮度，辅星、煞星分色，四化以禄权科忌标签标注
- 真太阳时校正（内置 520 个城市的经纬度）
- 1986–1991 年中国夏令时判定与提示
- 晚子时换日（23:00–23:59 按次日排盘）
- 空宫自动借对宫星曜显示
- 格局识别

### 三种视角

- **本命**：以本命命宫为纲
- **大限**：十二宫按大限命宫重排，附大限四化落宫
- **流年**：可选年份，十二宫按流年命宫重排

### 逐宫解读

- **本地知识库**：14 主星 × 9 个面向、12 宫职、五行局、四化、亮度、60+ 辅星杂曜释义，确定性生成，同盘恒得同结果
- **倪师《天纪》要点**：依开源语料归纳转述
- **AI 评语**：接入免费模型即时生成，标注「AI 生成」，可按命盘缓存
- **白话版 / 专业版可切换**，默认白话版

**白话版** —— 术语第一次出现就用日常话解释，判断依据与专业版一致

1. **性格**：命宫主星、亮度强弱、辅煞、身宫落点
2. **事业**：官禄宫主星、四化落点、当前大限的主题
3. **财运**：财帛宫与田宅宫
4. **婚姻**：夫妻宫主星、煞星带来的波折
5. **出门在外**：迁移宫
6. **精神状态**：福德宫
7. **健康**：疾厄宫的提醒，不判断寿数
8. **六亲速览**：父母、兄弟姐妹、子女、朋友下属各一句
9. **先天、这十年、今年**：三层四化分开，标出双禄、双忌、禄忌交战、忌处逢禄、禄忌对冲和宫干飞化
10. **大限节奏**：每十年一段，标出「你现在在这段」
11. **格局外号**：放在最后，只作总结；写了破格的只算接近

**专业版** —— 术语完整的逐宫细读，另有 AI 评语

1. **命局总览**：命宫 / 身宫 / 五行局 / 命主身主 / 阴阳、三方四正。格局名不在这里下结论
2. **十二宫详解**：每宫六层——宫职定位、主星落宫、亮度吉凶、吉煞星、生年与运限四化、对宫联动
3. **生年四化**：禄权科忌各一条
4. **四化层次**：生年、大限、流年分开；双禄、双忌、禄忌交战、忌处逢禄；化忌追踪；禄忌对冲；命官财夫迁福的宫干飞化
5. **命局基础**：五行局、命主、身主、阴阳男女与大限顺逆
6. **运限**：大限与流年
7. **格局**：文末的总结标签，列出等级、宫位、成立条件、破格因素与出处

### 相邻时辰对照

出生时辰不确定时，可把上一时辰、本时辰、下一时辰三个盘并排比对，逐行标出差异。

## 开发

```bash
npm run build     # 由 src/ 拼出 index.html
npm run check     # 只比对不写盘，确认没有意外漂移
npm test          # 亮度口径回归测试（约 15 秒）
node scripts/inspect.mjs   # 命令行排一张盘，查看完整结果
```

构建无需 `npm install`：脚本只用 Node 内置模块（Node ≥ 18）。

### 源码结构

```
index.html            发布产物（由 src/ 构建，勿直接改）
src/
  index.html          页面骨架，含五处注入点
  styles.css          全部样式
  interpret.js        四化层次与宫干飞化（白话版、专业版共用）
  plain-reading.js    白话版解读的文案库与生成器
  app.js              UI 层：表单、盘面渲染、解读渲染（未压缩，可读）
  engine.js           引擎层产物：iztro + lunar + 本地解读库 + buildReading（压缩，见下）
  engine/VERSION.json 引擎版本
  engine/PATCHES.md   引擎改动规则与记录
scripts/
  build.mjs           构建
  extract.mjs         一次性抽取（留作审计，可重跑校验同源）
  test-brightness.mjs 亮度口径回归
  inspect.mjs         单盘检视，命令行排一张盘看全部结果
```

引擎层是压缩产物，不参与常规编辑；改引擎的流程与已知陷阱见 [src/engine/PATCHES.md](src/engine/PATCHES.md)。

改解读文字**不需要碰引擎**：三层四化与飞化在 `src/interpret.js`，白话版在 `src/plain-reading.js`，专业版原有逐宫文案仍在 `engine.js` 的 `buildReading` 里，层次和格局顺序在 `src/app.js`。

## 技术

- 排盘内核：[iztro](https://github.com/SylarLong/iztro) + lunar-javascript
- 上游排盘层：[Renhuai123/ziwei-doushu](https://github.com/Renhuai123/ziwei-doushu)
- 构建：Node 脚本按注入点拼装，产出单个 HTML 文件
- 纯前端，无框架依赖，无构建产物外的运行时依赖
- 数据不上传；AI 评语除外（点击生成时会把命盘信息发送到第三方接口，不含姓名）
